# Deploy Base Model Plan

**Recommended for:** Users who want to deploy a base model as-is without fine-tuning. The user does not have a trained model and wants to select and deploy directly from the SageMaker Hub catalog.

1. **Define Use Case** - Capture the business problem, users, and deployment constraints. *(Reference: use-case-specification)*
2. **Select Base Model** - Filter the catalog by constraints and choose a model. *(Reference: model-selection)*
3. **Verify Environment** - Check SDK version, region, and execution role are configured. *(Reference: sdk-getting-started)*
4. **Deploy Model** - Create an endpoint for the selected base model. *(Reference: model-deployment)*
